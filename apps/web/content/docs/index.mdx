tsc-ts is a TypeScript compiler written in TypeScript and compiled to a native executable with [scriptc](https://scriptc.dev). It reads `tsconfig.json`, checks your program, and emits JavaScript and declaration files according to your compiler options.

## Get started

Install tsc-ts as a development dependency and check an existing project:

```sh
npm install -D tsc-ts
npx tsc-ts -p tsconfig.json --noEmit
```

Run the command from your project directory. `--noEmit` checks types without writing files. Remove it to emit the outputs enabled by your configuration.

The npm package installs a native executable for your operating system and architecture. See [getting started](/compiler/getting-started) for supported platforms and how to add tsc-ts to your package scripts.

## Compiler behavior

tsc-ts is a port of the TypeScript-Go 7.0.2 compiler. Its tests compare diagnostics, emitted files, module resolution, and API responses with a pinned upstream revision. Read [compatibility](/compiler/compatibility) for the tested surfaces and how to investigate a difference.

Source code, build instructions, and test results are in the [repository](https://github.com/vercel-labs/tsc-ts#readme).
