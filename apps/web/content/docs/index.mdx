tsc-ts is a TypeScript compiler written in TypeScript and distributed as a native executable.

## Quick start

Install tsc-ts in your project and check it without writing output:

```sh
npm install -D tsc-ts
npx tsc-ts -p tsconfig.json --noEmit
```
