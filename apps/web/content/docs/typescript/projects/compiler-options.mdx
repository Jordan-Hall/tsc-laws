This index covers the option names in the edition's [commandLineParser.ts](https://github.com/microsoft/TypeScript/blob/c63de15a992d37f0d6cec03ac7631872838602cb/src/compiler/commandLineParser.ts). It includes command-line-only names and historical names still recognized for compatibility diagnostics. Recognition does not mean a removed option remains usable or that every option belongs under `compilerOptions`.

The content checks compare these rows with the installed TypeScript option declarations, including build and watch options. Use the linked subject clauses for requirements and interactions; an option's short description is not a replacement for its checking algorithm.

## Values and effective defaults

Boolean flags use Boolean values in JSON. Lists and maps require their corresponding JSON structures. Command-line list spelling and aliases belong to CLI parsing rather than the JSON grammar. Invalid values and incompatible combinations are diagnosed.

Omitted values can derive from other options. `strict` supplies defaults for its member flags; `target` supplies a default library level and affects class-field semantics; Node and preserve module modes supply related resolution/interop defaults. `libReplacement` defaults to enabled in this edition. A generated `tsc --init` configuration is a recommendation, not the intrinsic default of every omitted option.

Supported target spellings include ES5 through ES2024 and ESNext, with ES6 as an ES2015 alias; the recognized ES3 spelling is obsolete. Module spellings include none, CommonJS, AMD, System, UMD, ES2015/ES6, ES2020, ES2022, ESNext, node16, node18, node20, nodenext, and preserve. Resolution spellings include node10/node, classic, node16, nodenext, and bundler. Accepted combinations must still satisfy [module resolution](/typescript/projects/module-resolution).

## Historical recognized options

These names remain in the edition's option declarations for compatibility handling. Several were removed in TypeScript 5.5 and cause diagnostics when used; documenting their names must not be read as recommending them.

| Option                           | Historical role                                                                  |
| -------------------------------- | -------------------------------------------------------------------------------- |
| `importsNotUsedAsValues`         | Older value-import elision policy; use modern explicit type-only/verbatim rules. |
| `out`                            | Older output-file spelling.                                                      |
| `charset`                        | Historical input-encoding option.                                                |
| `noImplicitUseStrict`            | Older strict-directive control.                                                  |
| `suppressExcessPropertyErrors`   | Historical excess-property suppression.                                          |
| `suppressImplicitAnyIndexErrors` | Historical implicit-index-any suppression.                                       |
| `noStrictGenericChecks`          | Historical generic comparison relaxation.                                        |
| `preserveValueImports`           | Older value-import preservation policy.                                          |
| `keyofStringsOnly`               | Historical restriction excluding numeric/symbol key behavior.                    |

See [TypeScript 5.5 removed options](https://www.typescriptlang.org/docs/handbook/release-notes/typescript-5-5.html#disabling-features-deprecated-in-typescript-50).

## Watch options

Watch configuration uses its separate `watchOptions` record or supported CLI spelling.

| Option                      | Effect                                                         |
| --------------------------- | -------------------------------------------------------------- |
| `watchFile`                 | Select supported file-event/polling behavior.                  |
| `watchDirectory`            | Select supported directory watching behavior.                  |
| `fallbackPolling`           | Select fallback when event watching is unavailable or limited. |
| `synchronousWatchDirectory` | Control supported directory-event synchronization.             |
| `excludeDirectories`        | Exclude directory patterns from relevant watching.             |
| `excludeFiles`              | Exclude file patterns from relevant watching.                  |

Watch exclusions affect events rather than universally prohibiting files from program semantics. Host behavior and invalidation assumptions remain material.
