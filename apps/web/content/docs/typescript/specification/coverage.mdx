This index lists every clause of the TypeScript 5.9.3 specification and the subjects it defines. It provides a review map for additions and edition changes. Coverage does not prove exhaustive correctness: the [conformance boundaries](/typescript/specification/conformance) state what the prose and checked witnesses establish.

JavaScript evaluation and standard runtime built-ins are incorporated through [ECMA-262](https://tc39.es/ecma262/). Host API declarations are environmental inputs, described in [libraries](/typescript/projects/libraries). This specification focuses on TypeScript's additional syntax, static semantics, and compiler/project observations.

Start with the [edition and checking context](/typescript). Consult [sources and verification](/typescript/sources) for the pinned source revision and discrepancy procedure.

## Maintenance requirements

When adding a feature or changing the edition, update its defining clause, this map, navigation, checked examples, and the option index where relevant. Version-specific rules must name the edition and evidence. A TypeScript 5.9 witness does not establish a TypeScript 7 or tsc-ts conformance result.
