title: Utility types
description: Standard transformations for object shapes, unions, functions, and promises.
---

Utility types are declared in TypeScript's standard libraries. They describe type transformations and do not perform corresponding runtime operations.

## Object transformations

| Utility        | Result                                            |
| -------------- | ------------------------------------------------- |
| `Partial<T>`   | Makes properties optional.                        |
| `Required<T>`  | Removes optional property modifiers.              |
| `Readonly<T>`  | Makes properties readonly.                        |
| `Pick<T, K>`   | Keeps the selected keys.                          |
| `Omit<T, K>`   | Removes the selected keys.                        |
| `Record<K, V>` | Creates properties for keys `K`, with values `V`. |

```ts
type User = { id: string; name: string; age?: number };
type Update = Partial<Omit<User, 'id'>>;
type Summary = Pick<User, 'id' | 'name'>;
const update: Update = { name: 'Grace' };
```

These transformations are generally shallow. `Omit` on a union does not automatically preserve each member's distinct properties; use an explicitly distributive conditional when that behavior is required.

## Union transformations

`Exclude<T, U>` removes union members assignable to `U`. `Extract<T, U>` keeps them. `NonNullable<T>` removes `null` and `undefined`.

```ts
type Status = 'idle' | 'running' | 'done';
type Active = Exclude<Status, 'idle'>; // "running" | "done"
type Present = NonNullable<string | undefined>; // string
```

`Exclude` works on union members, not on object keys. It cannot express every semantic set subtraction; `Exclude<string, 'a'>` remains `string`.

## Functions and promises

`Parameters`, `ConstructorParameters`, `ReturnType`, and `InstanceType` extract signature information. `Awaited` models unwrapping promise-like results. `ThisParameterType` and `OmitThisParameter` manipulate explicit receiver information.

Overloaded signature extraction generally uses the last signature. `NoInfer<T>` blocks inference candidates from a position while retaining its checking type.

See the [utility types reference](https://www.typescriptlang.org/docs/handbook/utility-types.html), [inference](/typescript/type-system/inference), and [async functions](/typescript/language/async).

## Library definitions and scope

Utility names are supplied by library declarations. Most are aliases built from mapped, conditional, and indexed-access types; some are compiler intrinsics or markers. Their availability depends on the selected library edition. They do not introduce runtime functions with the same names.

| Utility                             | Defined operation                                                                          |
| ----------------------------------- | ------------------------------------------------------------------------------------------ |
| `Partial<T>`                        | Homomorphic mapping adding optionality to properties.                                      |
| `Required<T>`                       | Homomorphic mapping removing optionality.                                                  |
| `Readonly<T>`                       | Homomorphic mapping adding readonly, including supported array/tuple behavior.             |
| `Pick<T, K>`                        | Select keys constrained by `keyof T`, retaining their corresponding values/modifiers.      |
| `Record<K, V>`                      | Construct properties or index domains for permitted key set `K`, each with value type `V`. |
| `Omit<T, K>`                        | Pick `Exclude<keyof T, K>`; keys need only satisfy the broad property-key constraint.      |
| `Exclude<T, U>`                     | Distribute over `T`, removing constituents assignable to `U`.                              |
| `Extract<T, U>`                     | Distribute over `T`, retaining constituents assignable to `U`.                             |
| `NonNullable<T>`                    | `T & {}` in this edition.                                                                  |
| `Parameters<F>`                     | Infer a parameter tuple from a constrained callable type.                                  |
| `ConstructorParameters<C>`          | Infer a parameter tuple from a constrained, possibly abstract constructor.                 |
| `ReturnType<F>`                     | Infer the result of a constrained callable type.                                           |
| `InstanceType<C>`                   | Infer the instance result of a constrained, possibly abstract constructor.                 |
| `Awaited<T>`                        | Recursively model supported Promise-like unwrapping.                                       |
| `ThisParameterType<F>`              | Infer an explicit receiver, or use `unknown` when not available.                           |
| `OmitThisParameter<F>`              | Remove an explicit receiver in its supported callable transformation.                      |
| `ThisType<T>`                       | Contextual object-literal receiver marker; has no ordinary members.                        |
| `NoInfer<T>`                        | Retain checking against `T` while blocking candidates from that occurrence.                |
| `Uppercase<S>` / `Lowercase<S>`     | Intrinsic full-string case transformations.                                                |
| `Capitalize<S>` / `Uncapitalize<S>` | Intrinsic initial-character case transformations.                                          |

## Mapping boundaries

`Partial`, `Required`, and `Readonly` are shallow: they transform top-level members and supported containers, not every recursively reachable object. `Pick` and `Omit` do not remove runtime fields. `Record<string, V>` permits an index domain but does not ensure every string key exists at runtime.

`Omit` is not a universal distributive union operation. It operates on the keys supplied by `keyof T`, so a union can lose variant-specific members. Define an explicit distributive conditional when preserving each alternative is the intended contract.

```ts
type Variant = { common: string; left: number } | { common: string; right: boolean };
type DistributedOmit<T, K extends PropertyKey> = T extends unknown ? Omit<T, K> : never;
const left: DistributedOmit<Variant, 'common'> = { left: 1 };
```

## Callable and constructor operations

Parameters and return inference from overloads ordinarily use the last signature. Generic callable inference can produce unknown or constrained results where a concrete argument is absent. These utilities are not call-site overload resolvers.

Removing `this` through `OmitThisParameter` can erase generic relationships and use the last overload under its definition. It does not create a bound function or supply a runtime receiver. `InstanceType` does not instantiate the constructor.

## Awaited operation

`Awaited<T>` preserves nullish types where relevant, then checks supported object types with a callable `then` contract. It infers the fulfillment callback's value and recursively unwraps it. A malformed noncallable fulfillment argument can produce `never`; ordinary nonthenable types remain themselves. It distributes through its conditional structure and remains subject to recursion limits.

```ts
type Resolved = Awaited<Promise<PromiseLike<string>> | number>;
const result: Resolved = 'ready';
const alternative: Resolved = 1;
```

The type alias models a result relationship. Actual Promise assimilation and asynchronous execution are runtime operations governed by JavaScript.

## Intrinsic and marker boundaries

`intrinsic` in the built-in declarations is compiler machinery, not a user-extensible implementation language for type functions. `ThisType` affects a supported contextual position, and `NoInfer` affects inference; neither supplies runtime members. The exact public definitions for this edition are in [lib.es5.d.ts](https://github.com/microsoft/TypeScript/blob/c63de15a992d37f0d6cec03ac7631872838602cb/src/lib/es5.d.ts).
