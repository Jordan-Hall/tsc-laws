---
title: Type inference
description: Initializer inference, contextual typing, and generic argument inference.
---

Inference supplies a type when an annotation or type argument is omitted. It uses the expression, candidate types, and surrounding context. The same expression can infer differently in a different context.

## Initializers

```ts
let count = 0; // number
const direction = 'up'; // "up"
const choices = [1, 'two']; // (string | number)[]
```

Mutable locations often widen literals. An empty array or missing initializer has additional inference rules; do not assume it behaves like a nonempty literal.

## Contextual typing

An expected type can supply types inside an expression. Function parameters frequently obtain types this way.

```ts
const names = ['Ada', 'Grace'];
const lengths = names.map((name) => name.length);
// name: string; lengths: number[]
```

Annotating a variable can also provide context to an object literal. `satisfies` checks a target shape while retaining the expression's resulting type, and can influence inference through that context.

## Generic calls

The checker infers type arguments by relating argument expressions to parameter types. Return context can also contribute. Constraints restrict candidates but are not always the inferred result.

```ts
function first<T>(values: readonly T[]): T | undefined {
  return values[0];
}
const value = first(['a', 'b']); // string | undefined
```

## Controlling an inference source

`NoInfer<T>` prevents a position from contributing candidates for `T`, while retaining the type's checking role.

```ts
function choose<T extends string>(values: readonly T[], fallback: NoInfer<T>): T {
  return values[0] ?? fallback;
}
choose(['red', 'blue'], 'red');
// @ts-expect-error: fallback cannot expand the choices inferred from values
choose(['red', 'blue'], 'green');
```

Give explicit type arguments or annotations when inference cannot express the intended contract. See [type inference](https://www.typescriptlang.org/docs/handbook/type-inference.html) and [`NoInfer`](https://www.typescriptlang.org/docs/handbook/utility-types.html#noinfertype).
