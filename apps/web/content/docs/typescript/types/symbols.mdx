title: Symbols and unique symbols
description: Symbol-valued property keys and declaration-specific unique symbol types.
---

`symbol` describes JavaScript symbol values. Symbols can be property keys without colliding with string keys of the same description.

```ts
const key = Symbol('id');
const object = { [key]: 1, id: 'text' };
const id = object[key]; // number
```

Two calls to `Symbol('id')` produce different values even though the description is the same. The description does not define identity.

## Unique symbol types

`unique symbol` gives a symbol declaration its own type identity. It is available for suitable `const` declarations and readonly static properties. Use `typeof` to refer to that particular declaration's type.

```ts
const first: unique symbol = Symbol('key');
const second: unique symbol = Symbol('key');
type First = typeof first;
const same: First = first;
// @ts-expect-error: a different declaration has a different identity
const different: First = second;
```

## Symbol keys in types

An object type can use a unique symbol as a computed property name. `keyof` can include symbol keys alongside string and numeric keys.

```ts
declare const tag: unique symbol;
type Tagged = { [tag]: 'user'; name: string };
type Keys = keyof Tagged; // typeof tag | "name"
```

This can support branding conventions, but a declaration alone does not attach a property to runtime values. If the symbol is declared ambiently, its runtime value must be supplied elsewhere.

## Well-known symbols

Properties such as `Symbol.iterator` connect objects to runtime protocols. A compatible type declaration describes the protocol; it does not install the method.

See [symbols](https://www.typescriptlang.org/docs/handbook/symbols.html), [iterators](/typescript/language/iterators), and [`keyof`](/typescript/type-operators/keyof).

## Symbol categories

`symbol` describes arbitrary symbol values. `unique symbol` describes a declaration-specific identity. A unique-symbol type is assignable to `symbol`, but an arbitrary symbol is not assignable to that identity. Different unique-symbol declarations are distinct even if their descriptions contain identical strings.

```ts
const left = Symbol('key');
const right = Symbol('key');
const general: symbol = left;
// @ts-expect-error: distinct unique-symbol declarations are not interchangeable
const exact: typeof left = right;
```

A unique-symbol annotation is restricted to permitted constant declarations and readonly static properties. A general mutable binding cannot promise a fixed unique identity. The type of a unique-symbol declaration is normally referred to through `typeof` rather than by naming a new arbitrary identity expression.

## Property keys

A unique symbol can name a specific computed property in an object or type. Such a property is distinct from any string with a matching display name. A broad symbol index signature describes arbitrary symbol keys. `keyof` can include unique-symbol identities and the broad `symbol` category where an index signature is present.

```ts
const metadata = Symbol('metadata');
type Record = { [metadata]: string; name: string };
const record: Record = { [metadata]: 'internal', name: 'item' };
const key: keyof Record = metadata;
```

An object type's string index signature does not automatically admit a symbol key. Symbol properties are omitted by operations that consider only string keys, such as `Object.keys`, but can participate in object spread at runtime according to JavaScript enumerability rules.

## Well-known-symbol checking context

Well-known symbol names, including `Symbol.iterator`, `Symbol.asyncIterator`, and disposal symbols, are declared by the selected libraries. The checker can recognize their type significance in iterable and resource operations. The declarations do not polyfill those symbols or their runtime protocols.

`Symbol.for` and `Symbol()` have different runtime identity behavior; neither call spelling creates an arbitrary source-level nominal type for every returned value. The library and inference context determine whether an expression supplies a unique identity or the general symbol type.
